# Briefs

A brief is any instruction you write for a subagent, a peer session, or a human.

- Run the brief through `unslop-writing-for-agents` before sending it.
- State the finish line: what done looks like and when to stop asking.
- Name the skills the reader should use. A subagent inherits none.
- Set depth with the effort level, since words in the brief do not change it. A simple question gets "Answer directly".
- Ask for reasons in the reply. "Explain in three sentences why you chose this" is the form.
- Pass a chart, screenshot, or diagram as the file itself.
- For design work, name the patterns to avoid, such as "no cream backgrounds, no pill-shaped buttons". "Avoid a generic look" says nothing.
